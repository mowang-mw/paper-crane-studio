# 三分钟演示指南

## 演示前准备

使用三个 PowerShell 终端启动基础服务：

```powershell
conda activate anime-platform
.\scripts\run_backend.ps1
```

```powershell
conda activate anime-platform
.\scripts\run_worker.ps1
```

```powershell
.\scripts\run_frontend.ps1
```

打开推荐项目：

```text
http://127.0.0.1:5173/?project=36d4bdd5-0e88-4509-a2f5-eba7727fd38b
```

推荐项目为 `深夜少女`。演示已有剧本、图片、旁白和成片，或执行“仅重新合成成片”，不需要启动 Qwen、llama-server 或 ComfyUI，也不会触发 Qwen3-TTS 推理子进程。开始前确认视频和三个逐镜头 WAV 可播放，浏览器音量正常。

## 三分钟讲解流程

### 0:00-0:20：平台定位与模型链路

在顶部“真实演示链路”说明：这是本地多模型动漫制作工作台，将故事依次交给 Qwen3-4B、Animagine XL 4.0、Qwen3-TTS Serena，再由 FFmpeg 合成 MP4。指出状态来自当前项目实际 Job 和 Export，不是写死的演示标签。

建议话术：

> 这个项目的重点是把文本、图像、语音和媒体处理组织成可运行、可追溯的生产流程；模型决定质量上限，平台保证它们能稳定组合。

### 0:20-0:45：选择真实项目

在左侧搜索 `深夜少女`，或选择“有真实成片”筛选。指出真实链路项目优先排序、当前项目高亮，并且 URL 中保存 project ID，刷新后仍能回到同一项目。

### 0:45-1:15：AI 剧本与三个镜头

查看“AI 剧本”摘要：Qwen3-4B、已完成、3 个镜头。展开后快速展示 ScriptV1 的角色、场景、画面描述和旁白。强调下游消费的是校验后的结构化剧本，而不是自由文本。

### 1:15-1:40：真实图片与旁白

展开“动漫画面”，展示三张 Animagine XL 4.0 关键帧；再到“配音与成片”播放一段 Serena WAV。指出图片和音频都有逐镜头追溯，真实任务失败不会静默回退 Mock。

### 1:40-2:10：播放最终成片

直接播放大尺寸视频，展示 Poster、中文字幕、镜头运动和中文旁白。简要指出当前成片采用静态动漫关键帧加 FFmpeg 运镜，不宣称角色连续动作视频。

### 2:10-2:30：媒体重合成

展示 `static`、`gentle_zoom`、`cinematic_pan` 选择，以及可选用户背景音和音量。指向“仅重新合成成片”并说明：该操作复用现有剧本、PNG 和 WAV，只运行 FFmpeg，适合现场比较运镜或混音；演示时不必真的等待完成。

### 2:30-2:50：Manifest 与零模型调用

下载或打开最新 Manifest，重点展示：

- `media_only: true`
- `reused_providers`
- `provider_calls` 中 script/image/audio 均为 0
- 来源 Job、运动模式、背景音、TimingPlan 和素材追溯

说明“最初由真实模型生成”和“本次导出复用素材”是两个独立事实。

### 2:50-3:00：8GB 工程取舍与升级路径

说明 RTX 4060 8GB 通过 Qwen -> 释放 -> Animagine -> 释放 -> TTS -> FFmpeg 的阶段式 GPU 交接跑通真实链路。更大显存可替换更强模型，但角色一致性和连续视频仍需要新的平台阶段，不是简单换模型即可完成。

## 现场不要做的操作

- 不要现场重新生成全套真实剧本、三张图片和三段 TTS；耗时和 GPU 交接会破坏三分钟节奏。
- 不要同时启动 llama-server 与 ComfyUI；Qwen3-TTS 没有需要手动常驻启动的服务，真实 TTS 由 Worker 在需要时调用受控子进程。
- 不要删除推荐项目或其素材。
- 不要用 Mock 结果替代真实链路证明；直接展示项目状态和 Manifest。
- 不要临时更改模型参数、权重路径、数据库或媒体文件。
- 不要把 `MEDIA_RERENDER` 描述为重新运行模型，它是 FFmpeg-only 导出任务。

## 演示失败时的最短恢复

- 页面打不开：确认后端和前端两个终端仍在运行。
- Job 不推进：确认 Worker 终端仍在轮询。
- 项目没选中：使用直达 URL 或搜索 `深夜少女`。
- 视频暂时未加载：刷新当前项目，保留 URL 中的 `project` 参数，再检查后端媒体服务。
- 不要为了恢复播放而启动任何模型服务；已有素材播放与下载不依赖模型。

## 演示完成标准

演示者应能在三分钟内看到：原始故事、结构化三镜头剧本、三张真实动漫图、真实 Serena 旁白、最终 MP4、模型链路、8GB 调度方式，以及 Manifest 对真实来源和零 Provider 调用重合成的证明。
